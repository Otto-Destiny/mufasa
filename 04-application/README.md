# Application

This layer is the offline product surface. It coordinates retrieval, local model inference, validation, resource limits and evidence presentation on the target laptop.

![MUFASA application architecture](./images/application-architecture.svg)

See [application-architecture.md](./application-architecture.md) for the desktop, local-service and optional local-Wi-Fi interface design.

Packaged binaries and generated application bundles are release artifacts and are not stored in Git.
